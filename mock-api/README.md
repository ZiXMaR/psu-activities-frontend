# Mock API — เว็บกิจกรรมพัฒนานักศึกษา

ชุด Mock REST API สำเร็จรูปสำหรับข้อสอบภาคปฏิบัติ (POC) ตำแหน่งนักวิชาการศึกษา
ผู้เข้าสอบใช้ API ชุดนี้เป็นแหล่งข้อมูลของหน้าเว็บ (Front-end) ไม่ต้องพัฒนา Back-end เอง

## วิธีรัน (ต้องติดตั้ง Node.js ก่อน)

```bash
# วิธีที่ 1: รันได้ทันทีโดยไม่ต้องติดตั้ง
npx json-server --watch db.json --port 3001

# วิธีที่ 2: ติดตั้งแล้วรันผ่าน script
npm install
npm start
```

เมื่อรันสำเร็จ API จะให้บริการที่ `http://localhost:3001`

## Endpoints

### กิจกรรม (Activities)

| วิธี | Endpoint | คำอธิบาย |
|------|----------|----------|
| GET | `/activities` | รายการกิจกรรมทั้งหมด |
| GET | `/activities/:id` | รายละเอียดกิจกรรมตาม id |
| POST | `/registrations` | ส่งข้อมูลการลงทะเบียนเข้าร่วมกิจกรรม |
| GET | `/registrations` | รายการการลงทะเบียนทั้งหมด |
| GET | `/registrations?activityId=:id` | รายชื่อผู้ลงทะเบียนของกิจกรรมนั้น |

### การแบ่งหน้า (Pagination)
```
GET /activities?_page=1&_limit=9
```
จำนวนรายการทั้งหมดจะอยู่ใน response header `X-Total-Count`

### การค้นหา (Search) — ค้นทุกฟิลด์
```
GET /activities?q=อาสา
```

### การกรองตามประเภท (Filter)
```
GET /activities?category=กีฬา
```
ค่า `category` ที่มีในระบบ: `อบรม/สัมมนา`, `จิตอาสา`, `กีฬา`, `ศิลปวัฒนธรรม`, `พัฒนาทักษะอาชีพ`

### การเรียงลำดับ (Sort)
```
GET /activities?_sort=date&_order=asc
```

## ตัวอย่างข้อมูลการลงทะเบียน (POST /registrations)

```json
{
  "fullName": "สมชาย ใจดี",
  "studentId": "6510110001",
  "faculty": "คณะวิศวกรรมศาสตร์",
  "email": "student@example.com",
  "phone": "0812345678",
  "activityId": 1,
  "consent": true
}
```
json-server จะเพิ่ม `id` ให้อัตโนมัติและตอบกลับสถานะ 201 พร้อมข้อมูลที่บันทึก

## หมายเหตุ
- ข้อมูลกิจกรรมมีทั้งหมด 16 รายการ ครอบคลุม 5 ประเภท เพื่อให้ทดสอบการค้นหา การกรอง และการแบ่งหน้าได้
- หากต้องการใช้งานผ่านเครือข่าย/อุปกรณ์อื่น สามารถเพิ่ม `--host 0.0.0.0` หรือนำไป deploy บนบริการโฮสต์ฟรีได้
